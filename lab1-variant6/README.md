## 3. Используемые формулы

### Квадратный корень

Решается уравнение:

`x² - a = 0`.

Итерационная формула Ньютона (формула Герона):

`x_(n+1) = 1/2 * (x_n + a/x_n)`.

Критерий остановки:

`|x_(n+1) - x_n| < ε`.

Для варианта 6 начальное приближение:

`x₀ = a/2 = 6.5`.

### Кубический корень

Решается уравнение:

`x³ - b = 0`.

Итерационная формула:

`x_(n+1) = (2*x_n + b/x_n²) / 3`.

Для отрицательного `b` в программе отдельно обрабатывается знак.

Для варианта 6:

`b = -27`, `x₀ = |b|/2 = 13.5`.

### Натуральный логарифм

Используется ряд:

`ln(c) = 2 * (y + y³/3 + y⁵/5 + ...)`

где

`y = (c - 1)/(c + 1)`.

Каждый следующий член вычисляется через предыдущую степень `y` с использованием `y²`.

Критерий остановки:

`|t_k| < ε`.

Для `c = 7`:

`y = 6/8 = 0.75`.

### Анализ сходимости (требование Д1)

**Квадратный корень (√13):**  
Квадратичная сходимость. Число верных знаков примерно удваивается на каждой итерации. После 5-й итерации достигнута машинная точность.

**Кубический корень (∛−27):**  
Начальное приближение x₀ = 13.5 далеко от корня (= 3), поэтому первые итерации идут почти линейно. Квадратичный режим наступает с 6–7-й итерации. Всего 8 шагов. Знак восстановлен корректно.

**Натуральный логарифм (ln 7):**  
Линейная сходимость. При |y| = 0.75 требуется 15 членов ряда. Погрешность имеет порядок ε.
